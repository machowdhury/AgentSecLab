    Hands-on agentic AI security academy

    Learn to investigate how AI agents actually behave.

    AgentSecLab is a learning range. You predict what a security control will do, run a real experiment against a deliberately vulnerable lab, and prove what happened from recorded evidence.

    Start the MCP workshop New here? Start with AI basics

    Core principle: a control decision is not execution, and execution is not proven until you can point to the event that records it.

    What you will be able to do

    • Explain the system

      Describe how an agent, its tools and a security control fit together, in plain language.

    • Predict before you look

      Commit to what you expect a control to decide before any evidence is shown.

    • Investigate evidence

      Answer security questions from real events and name the event behind each answer.

    • Compare and explain

      Compare an ATTACK and a RETEST run and separate what was observed from what you infer.

    First time here?

    You do not need an AI or security background. Follow this route in order.

    1. 1Understand how models, agents and tools work
    2. 2Meet the lab and its boundaries
    3. 3Predict what the control will decide
    4. 4Investigate your first run
