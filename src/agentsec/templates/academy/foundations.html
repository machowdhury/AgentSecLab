    Words you will meet

    Agent
    A system that uses a model to choose and request actions.
    Tool
    A capability an agent can request, such as looking up a record.
    Control
    A mechanism that decides whether a requested action may proceed. In this lab: CTRL-MCP-001.
    Telemetry
    Events a system records while it works.
    run.id
    The identifier that ties every event of one experiment together.
    LIVE / REPLAY / SYNTHETIC / UNAVAILABLE
    LIVE is a run launched now. REPLAY is a recording of a real past run. SYNTHETIC would be generated data (this workshop does not use it). UNAVAILABLE means the evidence could not be loaded.
