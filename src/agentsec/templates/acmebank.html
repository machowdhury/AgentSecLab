Words you will need

      

        
Tool
Code an agent can ask to run. It reaches real data or performs a real action, so it is where authority matters.

        
MCP
Model Context Protocol — the convention by which an agent asks a server for a tool. Asking is not the same as being granted.

        
Control decision
What the policy decision point concluded: ALLOW, DENY or ERROR. It is a decision, not an outcome.

        
Execution
Whether the handler actually began. This is a separate fact and needs its own evidence. ALLOW does not prove execution, and DENY alone does not prove nothing else ran.

        
Telemetry
Structured records AcmeBank emits as the run proceeds, tied together by run.id.

        
What Splunk is doing
Indexing that telemetry so you can reconstruct the run afterwards. Splunk observes. It does not authorize anything.
