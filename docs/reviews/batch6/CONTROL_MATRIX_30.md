## 4. Top gaps (ranked)

1. **Kill switch (18), micro-VM (1), multi-modal (14), dual-model (30), semantic anomaly (26) do not exist.** Nothing in `src/`, `scripts/`, `docker/`, `config/` to build on.
2. **No identity or credential substrate (6, 7, 23, 9).** Agent identities are labels, CTRL-IDENTITY-001 is observe-only, no token issuance or expiry, no A2A endpoint. `CTRL-AUTHN-001` and `CTRL-A2A-005` are design text.
3. **Human approval (16) has no workflow.** The agent is blocked from `issue_loan_offer`, but nothing asks, records or verifies an approver. LAB-HITL-APPROVAL says `NOT PROVEN` itself.
4. **Audit integrity (17) is a hash per event only.** No chain, no append-only store, no tamper test; HMAC protects only the Loan Desk verification files. Raw note preview (400 chars) goes to Splunk, which also weakens privacy-aware (13) claims.
5. **Containment (2) is a single bridge network.** No `internal: true`, no egress allowlist; all services (incl. Ollama) share one mesh. Only host port bindings are tested.
6. **Observe-only controls (12, 21, 22):** RAG, memory, identity, result and metadata trust record but do not prevent. Defences work only because CTRL-MCP-001 sits downstream.
7. **Cost (28), limits (3), loops (24) are ceilings without differential or accounting.** No token/spend budget, no cycle detection across agents, no baseline-vs-hardened evidence for the limits.
8. **Red teaming and drift (27, 29) are manual host scripts.** No CI gate, no stored baseline, garak never run in this tree, bench scripts untested.
9. **Immutable prompts (5), PII redaction (13) and homogeneous guards (25) lack tests.** Behaviour is by convention (prompt constant) or narrow regex; no cross-model/framework equivalence evidence.
10. **Evidence base is narrow:** one real-model lab (Loan Desk), scripted proposers elsewhere; Loan Desk is not in the launch catalog or the registry-driven Academy lab list (curriculum entry exists in `learning/academy/curriculum.json:270`).
