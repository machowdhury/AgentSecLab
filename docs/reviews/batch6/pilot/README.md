# Loan Desk five-person pilot package

**Status: NOT CONDUCTED.** This package is prepared, not run. No participant has used it. No result in this
repository is human evidence until a completed observer sheet and feedback form exist for a real participant.

| File | Use |
|---|---|
| `FACILITATOR_GUIDE.md` | Recruiting, consent, setup, what to say and not say, safety, data handling |
| `TASK_SCRIPT.md` | The eleven tasks read aloud, pass rules and time boxes |
| `OBSERVER_CHECKLIST.md` | One sheet per participant: times, hints, errors, barriers, quotes |
| `COMPREHENSION_AND_RUBRIC.md` | Four comprehension prompts, a blind two-rater rubric, a confidence question |
| `FEEDBACK_FORM.md` | Post-session form: difficulty, clarity, accessibility, free text |
| `results_template.csv` | One row per participant; leave every cell empty until a session happens |

Reporting rule: counts only ("3 of 5"), never percentages. Report automated checks and human results in separate sections.
Success thresholds are fixed before the first session (see `FACILITATOR_GUIDE.md`) and are not changed afterwards.
