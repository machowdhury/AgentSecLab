# SPLUNK KNOWLEDGE OBJECT REVIEW

## Q-GARAK-EVALUATION

OBJECT: `Q-GARAK-EVALUATION.spl`
TYPE: INVESTIGATION SEARCH
PURPOSE: Reconstruct one or more indexed adversarial model evaluations with
native result, provenance, target, and correlation identity.

SECURITY / OPERATIONAL QUESTION:

What bounded evaluation did garak report, and can the indexed row be traced to
the preserved native report without interpreting PASS/FAIL as authorization?

EVIDENCE REQUIRED:

Evaluation sourcetype, ExternalEvidence fields, native evaluation fields, raw
reference/SHA-256, and correlation identity.

TELEMETRY SOURCE:

`agentsec:external:evaluation`, generated by `hec_event` in
`src/agentsec/external_evidence/garak_pack.py`.

INDEXED FIELDS VERIFIED: YES

FIELD CONTRACT: PASS

Fields verified live: timestamp, evidence ID, producer, provider, class, tool,
version, target type/id, native result, probe/detector/counts, raw reference,
raw SHA-256, correlation method/value. Unknowns remain absent.

CORRELATION CONTRACT: PASS

`identity_tuple` links native run, probe, detector, and model. It is not an
AgentSec run ID or causal runtime relationship.

SPL CORRECTNESS: PASS

The query restricts index and sourcetype, normalizes multivalue JSON fields,
and displays provenance. It performs no join or authorization inference.

NO-DATA SEMANTICS: PASS

Dashboard consumer displays `NO EVIDENCE FOUND` and diagnostic checks. Zero
rows is not SAFE.

PERFORMANCE: PASS for bounded local lab / NOT MEASURED for larger retention

The index and sourcetype predicates are selective. `earliest=0` is intentional
for committed replay evidence but should not be copied into an unbounded
production search.

CIM: DEFERRED

No TA/CIM applicability is claimed. This requires external validation.

KO DUPLICATION: NONE

DETECTION READINESS: HUNT ONLY

LIVE SPLUNK VALIDATION: PASS

DASHBOARD CONSUMER: YES — `ws_lab_external_evaluation_garak`

LIMITATIONS:

One canonical local-model specimen; no fresh garak execution in this phase.
Native PASS is not universal safety.

VERDICT: PUBLISH

## Q-EXTERNAL-EVIDENCE-PLANES

OBJECT: `Q-EXTERNAL-EVIDENCE-PLANES.spl`
TYPE: INVESTIGATION SEARCH
PURPOSE: Compare three evidence planes without joining them or claiming causality.

SECURITY / OPERATIONAL QUESTION:

Are runtime telemetry, static scanner findings, and adversarial evaluations
present as distinct indexed evidence sources?

EVIDENCE REQUIRED:

Three sourcetypes, event names, external classes, correlation methods, total
counts, and distinct raw counts.

TELEMETRY SOURCE:

`otel:agentic:json`, `agentsec:scanner:finding`, and
`agentsec:external:evaluation` in `agentsec_telemetry`.

INDEXED FIELDS VERIFIED: YES

FIELD CONTRACT: PASS

CORRELATION CONTRACT: NOT APPLICABLE

The search groups planes. It does not correlate individual events.

SPL CORRECTNESS: PASS

The `case` is exhaustive for the three restricted sourcetypes. `count` and
`dc(_raw)` intentionally expose duplicate submission behavior. Event names are
normalized before aggregation.

NO-DATA SEMANTICS: PASS

The consumer says no result is missing evidence, not safety. A missing plane
requires ingestion/time-range diagnosis.

PERFORMANCE: PASS for bounded local lab / NOT MEASURED for larger retention

One index scan with three explicit sourcetypes and `stats`; no `join`,
`transaction`, `map`, wildcard index, or detector scheduling. `earliest=0` is a
replay-workshop choice.

CIM: DEFERRED

KO DUPLICATION: NONE

DETECTION READINESS: HUNT ONLY

LIVE SPLUNK VALIDATION: PASS

Measured rows included `RUNTIME`, `STATIC FINDING`, and
`ADVERSARIAL EVALUATION`.

DASHBOARD CONSUMER: YES — `ws_lab_external_evaluation_garak`

LIMITATIONS:

Adjacency and shared time range do not establish causality. Counts describe
the indexed copy, not security coverage.

VERDICT: PUBLISH
