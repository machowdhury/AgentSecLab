# L8 live Splunk validation

Date: 2026-09-25

## Scope

Live Splunk was used only to validate the indexed evidence required by
`PRIV-2026-001`. It did not authorize, execute, minimize, or block either run.

## Specimens

- Full record / ATTACK: `d27562be-3bb9-4643-ab88-5100173426a5`
- Minimized record / RETEST: `46f030ad-8b62-40d0-9c0e-fd4206b7bc47`

Both were generated by the local fixture-backed privacy runner.

## Measured result

The live query counted distinct raw events by run ID and collected mode,
decision, and event names from `index=agentsec_telemetry` /
`sourcetype=otel:agentic:json`.

Each run had seven distinct raw event payloads:

1. `agentsec.run.started`
2. `agentsec.hop.started`
3. `agentsec.control.decision`
4. `agentsec.mcp.started`
5. `agentsec.mcp.completed`
6. `agentsec.hop.completed`
7. `agentsec.run.completed`

Each had CTRL-MCP-001 decision `ALLOW`. Runtime evidence independently records
one handler invocation and completion for each specimen. The distinct raw
event count equals the seven local events for each run.

After local app restaging, the same run IDs had 21 indexed rows each while
remaining at seven distinct `_raw` values. This is duplicate ingestion of
three copies, not three runtime executions. The comparison search remained
stable: both modes showed ALLOW and completion; only ATTACK showed the
`account_balance_band` marker in the bounded preview. Investigators must not
read duplicate indexed rows as additional runtime actions.

## Interpretation

This is `MEASURED` live Splunk evidence of the bounded copies and `OBSERVED`
local runtime evidence. It supports correlation and completeness for these
specific distinct event packs. Duplicate ingestion means total row count is
not a completeness measure for these restaged copies. This does not prove provider behavior, retention,
deletion, model/RAG/memory processing, a production breach, or universal
privacy control effectiveness.

## Environment note

The Splunk CLI warned that server-certificate hostname validation is disabled
for this local lab CLI connection. No certificate material was added or
validated by L8. This local configuration must not be represented as a
production transport-security posture.
