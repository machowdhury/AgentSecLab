# LIVE vs REPLAY learner guide (Phase 17B)

Neither mode is “better.” They teach different skills.

## LIVE

You create fresh evidence. Attack Service mints new run.ids. Hunt those ids in Search. Studio tokens are **not** that launch.

Use LIVE to practice: predict → launch → wait → search → defend → retest → compare.

## REPLAY

You investigate existing canonical specimens. There is no Attack Service launcher on that workshop. Investigate specimen dropdown binds historical run.ids. Bound tables are Path B.

Use REPLAY to practice reconstruction when you cannot or should not mint a new run.

## How to tell immediately

- Home PATH marks each lab LIVE or REPLAY.
- LIVE workshops say Launch ATTACK (LIVE) and point at Attack Service.
- REPLAY workshops say **REPLAY SPECIMEN** / **REPLAY workshop** and “historical evidence, not a launch you just minted.”
- A header that says LIVE EVIDENCE on a workshop without a launcher is a defect. 17B removed those on MCP-003/004/005/006, catalog, and scanner.

## What REPLAY is still useful for

Scope, resource, result trust, confused deputy, catalog metadata, scanner-vs-runtime. Those remain REPLAY on purpose. Do not treat a REPLAY table as a run you just launched.

## Official historical ids

Some LIVE labs also show canonical REPLAY copies in Studio. Those copies are labeled REPLAY. Your Attack Service UUID is LIVE.
