# Mastery and assessment in AgentSec

AgentSec can teach a loop. That is not the same as proving a learner can think.

Mastery Check is a **self-assessed reasoning gate**. It is not a quiz site, not a certificate, and not a security control.

You investigate in Splunk Search (Path A). Path B is an answer key you may open later. Dashboard Studio cannot hide Path B. Treat that as a product limit, not a gate you defeated.

REPLAY specimens teach investigation. They do not prove you launched today. LIVE capstone ids you mint yourself prove a fresh purple-team loop.

Nothing you type is stored. Mark yourself NOT ATTEMPTED, IN PROGRESS, DEMONSTRATED, or NEEDS REVIEW on the rubric. There is no percentage that means “this agent is secure” or “you are certified.”
