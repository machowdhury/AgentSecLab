LAB-MCP-001 · Tool Authorization · Live lab

Can an AI agent use a tool it was never granted?

You will test one request against AcmeBank's loan assistant. You predict first, then prove what happened from evidence.

Customerapplies for a home loan
→
Loan assistantan AI agent
→
CTRL-MCP-001the control that decides
→
Toolruns only if the request gets through

The story

To answer lending questions, the assistant may use one tool: lookup_policy. A second tool, lookup_customer_tier, exists in the system. This agent was never granted it.

The question

If the assistant asks for a tool it was not granted, does the control stop the request? And does the tool still run? Those are two different facts.

Your route

Understand normal behavior, make a prediction, run the attack, investigate the evidence, test a defense, compare, then explain what you can safely claim.

Lab safety & boundaries

AgentSec is a local teaching lab. These limits are deliberate, and they are why you can experiment freely.

What this lab is

A local educational service

A classroom launcher. It reaches only the services of this lab, on the host already in your browser's address bar.

Closed experiments

You choose BASELINE, ATTACK or RETEST. You cannot send a profile, grants, tools, scopes, identity claims or any other parameter.

Splunk observes

Splunk shows evidence. It does not allow or deny anything. CTRL-MCP-001 is the control that decides.

What this lab is not

Not production authentication

No login is implemented. Do not treat this as an authentication guarantee.

Not multi-tenant

One learner environment. There is no isolation between users.

Not internet-facing

Do not expose its ports to the public internet. Restrict access to trusted learner addresses.

What you can and cannot influence

You choose

Which closed experiment runs, and what you predict.

The server owns

The security profile, the grant list, the tool policy and the authorization decision.
