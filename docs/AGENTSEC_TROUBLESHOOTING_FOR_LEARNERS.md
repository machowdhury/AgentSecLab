# Troubleshooting for learners (Phase 17B)

This page is for people using the Academy product. It is not operator runbooks.

## Splunk Search returned no rows

1. Did you wait until Attack Service said **EVIDENCE READY**? HEC success is not searchable yet.
2. Did you paste the LIVE run.id you just copied, in quotes?
3. Did you use `index=agentsec_telemetry sourcetype=otel:agentic:json`?
4. If this is a REPLAY specimen, this volume may not contain that historical id. Empty is not DENY.

Empty is not prevention. Empty is not “the lab is broken” by itself.

## I pasted the wrong run.id

Search for the id Attack Service showed after **this** launch. Studio Investigate specimen is a different, historical copy.

## Attack Service is unavailable

The launcher is down. You cannot mint LIVE evidence. You can still study REPLAY workshops and Home ORIENT. Do not invent a control decision.

## AcmeBank is unavailable

Launch will fail. That is not DENY and not a passed RETEST.

## Splunk is unavailable

You may still have a run.id from a successful launch, but you cannot hunt yet. Do not conclude SAFE.

## REPLAY evidence missing on this volume

Path A will be empty. Use another published specimen from Investigate, or treat Path B tables as the expected shape of a historical copy — still not a fresh launch.

## This REPLAY lab has no RETEST button

Correct. LIVE RETEST is only on LIVE labs. Reconstruct the historical RETEST specimen instead.

## I see ALLOW

That is a control decision. It is not execution. Hunt whether the handler or LLM actually started.

## I see DENY

That is a control decision. It does not by itself prove the handler never ran. Runtime handler count is authoritative where the lab defines it.

## I see OBSERVE

Classification. Not ALLOW. The PDP for tools remains CTRL-MCP-001.

## Mastery Check looks like a test I am failing

It is not scored. It is not a certificate. FOUNDATIONAL NONE cards do not require Search.
