# Learning Review

Teach the requested feature using actual AgentSec code.

Explain:

1. Architecture simply.
2. Main components.
3. Legitimate request path.
4. Attack path.
5. Exact files involved.
6. Trust boundary.
7. Security invariant.
8. Reference control.
9. Telemetry.
10. Splunk investigation.
11. Tests.
12. Important limitations.

Then give me 10-15 questions.

Do not immediately give answers.

After I answer, grade:

CORRECT
PARTIALLY CORRECT
INCORRECT

Then explain what I misunderstood.
