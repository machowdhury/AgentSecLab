# Architecture Review

Do not implement yet.

For the requested feature determine:

1. Problem being solved.
2. Learning objective.
3. Existing AgentSec components involved.
4. Existing AgentWatch functionality that may be reusable.
5. Proposed components.
6. Data flow.
7. State.
8. Trust boundaries.
9. Attacker-controlled inputs.
10. Security invariants.
11. Failure modes.
12. Observability requirements.
13. Splunk requirements.
14. Testing strategy.
15. Alternatives considered.
16. Why the proposed design is simplest.

Create an architecture proposal before coding.

Clearly identify anything uncertain.

Stop before implementation.
