```text
AUTHORIZED ACTION != AUTHORIZED DATA USE
```

same legitimate support task. CTRL-MCP-001 returns ALLOW and the same tool
completes in both. The ATTACK specimen supplies a full synthetic customer
record; the RETEST supplies only task-required fields.
